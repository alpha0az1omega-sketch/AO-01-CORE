# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-10-29
### Added
- **Core Architecture**: Foundation, Security, and Forge directories.
- **Local AI Agent**: `alpha_brain.py` with MCP, PDF RAG, TTS, and STT capabilities.
- **3D Portal**: Sovereign Universe built with Three.js, featuring the Diamond Qubit and interactive UI.
- **Blockchain**: AlphaCoin (ERC-20) and AlphaNFT (ERC-721) contracts deployed on local Anvil network.
- **Documentation**: Chronology, Psychology, and I-Storytelling guides.
- **Community**: 105 Challenges (XP system) for future Human-AI collaboration.
- **Security**: `.gitignore` implemented to protect private vaults and configuration files.

### Fixed
- Resolved connection issues between the 3D Portal and MetaMask on the local network.
- Fixed terminal syntax errors during smart contract compilation.
