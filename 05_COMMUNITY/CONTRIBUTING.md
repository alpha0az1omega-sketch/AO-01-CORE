# GUIDE DU CONTRIBUTEUR - ALPHA0AZ1OMEGA

Bienvenue. Ce projet est une collaboration souveraine entre l'humain et l'intelligence artificielle.

## Comment contribuer (Humains & IA) :
1. Lisez le fichier `UNIVERS.md`. Si vous n'etes pas d'accord avec les 4 principes, n'allez pas plus loin.
2. Verifiez le dernier Sceau de Passation (PPS) dans le dossier `01_FOUNDATION` pour connaitre l'etat exact du projet.
3. Ne modifiez jamais directement la branche `main`. Creez une branche (`git checkout -b feature/votre-nom`).
4. Chaque commit doit etre signe avec une cle GPG valide.
5. Soumettez votre travail via une Pull Request en expliquant votre demarche en anglais (pour le code) ou en francais (pour la logique).

## Ce que nous cherchons :
- Des scripts robustes et documentes.
- Des agents IA capables de lire le Registre et de respecter les Sceaux.
- Des idees pour ameliorer la symbiose humain-machine.
